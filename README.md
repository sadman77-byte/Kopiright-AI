# Kopiright AI

**A metadata-guided, human-in-the-loop academic paper replication and export system.**

Also described as: *Metadata-guided scholarly analysis generator*.

Kopiright AI helps users work with academic research papers and books when full-text access is limited. Using only metadata (title, author names, year, and optionally DOI), the system guides the user through structured generation of a complete, formatted scholarly document that closely follows the style, structure, length, and academic conventions of the original work.

---

## Key Features

- **Metadata-driven search & generation**  
  Search and generate from paper/book titles, scholar/writer names, publication year, and optional DOI.

- **Human-in-the-loop selection**  
  Presents multiple candidate options so the user can accurately choose the intended work.

- **Full-structure paraphrasing**  
  Produces a complete academic-style document that mirrors the original’s section structure, argumentation flow, word choices, sentence style, and approximate length — without omitting major parts.

- **Citations & references rebuilt**  
  Reconstructs in-text citations and a full reference list at the end of the document.

- **Publication-ready formatting**  
  - 12 pt Times New Roman  
  - Double spacing  
  - 16:9 layout suitable for on-screen reading and export  
  - Clean academic appearance

- **Export options**  
  - Copy the full generated text  
  - Download as a PDF that resembles a published paper

- **Branding**  
  Generated documents are presented under the name **Kopiright AI**.

---

## How It Works (5 Steps)

1. **Metadata Input**  
   When the user does not have access to a research paper or book, they provide the title, author(s) name(s), and publication year (DOI optional). The system uses this metadata to locate and prepare the corresponding scholarly content.

2. **Candidate Selection**  
   The system presents 3–4 candidate options. The user selects the correct one to ensure accuracy.

3. **Confirmation / Same Metadata**  
   If the user does not wish to change the topic, the same title, author name(s), and year are retained for generation.

4. **Generation**  
   The system produces a full academic document in its own language. It paraphrases the content while preserving the overall structure and coverage of the original work. In-text citations are reconstructed, and a complete References section is included at the bottom when applicable.

5. **Export**  
   The finished document can be copied in full or downloaded as a PDF formatted like a published paper (12 pt Times New Roman, double-spaced, 16:9 presentation).

---

## Design Philosophy

Kopiright AI is built around a **metadata-guided, human-in-the-loop** approach. It does not claim to replace legitimate access to published works. Instead, it assists users who only have bibliographic information by generating a structured, academically styled reconstruction that can be reviewed, edited, and exported for personal study or drafting purposes.

All generated content is produced under the system name **Kopiright AI**.
